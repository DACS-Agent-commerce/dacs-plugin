Set up your Demos wallet

  1. Install the Demos wallet extension in this browser, or enable it if it is already installed.
  2. Open the extension and choose Create for a new account, or Import for an account you already have. This happens only inside your wallet. On this extension path, this page never asks for your recovery phrase or private key.
  3. Come back to this page and select Check for wallet again. Then connect, and the portal receives only your public address.

This page cannot see which network your wallet uses. Check that it is set to Demos testnet in the wallet itself.

Optional: experimental embedded wallet

Instead of the extension, you can use a test wallet that runs only in this page. It is experimental, local-only and not security reviewed. Your recovery phrase and password stay in this page and are never sent to ChatGPT, an AI model or the DACS server. By default it supports sign-in and wallet linking only: payments, listing publication and identity changes are not available with it, so use the Demos wallet extension for those. Only a server explicitly set up with a local SIMULATED fixture chain also allows them, and only against that fixture.
